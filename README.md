Это консольная утилита на Node.js для работы с внешним REST API. Она принимает название города, получает по нему прогноз погоды из открытого API Open-Meteo, выводит результат в читаемом виде в терминал и сохраняет отчёт в файл.

##  Требования к окружению
* Node.js версии 20 и выше.
* Менеджер пакетов npm.

##  Инструкция по установке
1. Скачайте файлы проекта.
2. Откройте консоль в папке с проектом и установите зависимости командой:
   `npm install`
3. В репозиторий добавлен файл `.env.example`. Скопируйте его, переименуйте копию в `.env` и оставьте в корне проекта.

##  Переменные окружения
Настраиваемые параметры вынесены в переменные окружения:
* `GEO_API_URL` — базовый URL для геокодинга.
* `WEATHER_API_URL` — базовый URL для прогноза погоды.
* `API_TIMEOUT` — значение таймаута для ограничения времени запроса (по умолчанию 5000 мс).
* `REPORTS_DIR` — каталог отчётов.

##  Инструкция по запуску
Запуск утилиты выполняется командой вида:
```bash
node src/index.js --city "Нижний Новгород" --days 3
```

### Параметры:
* `--city` **(обязателен)** — название города. Поддерживает несколько городов через запятую (например: `--city "Нижний Новгород, Москва"`).
* `--days` *(необязателен)* — количество дней для прогноза. По умолчанию 3, допустимый диапазон 1-7.
* `--no-cache` *(необязателен)* — флаг принудительно выполняет запрос заново, игнорируя сохраненный файл кэша.

Пример запуска со всеми параметрами:
```bash
node src/index.js --city "Нижний Новгород, Москва" --days 5 --no-cache
```

##  Обработка ошибок и коды завершения
Утилита завершается с кодом `0` при успехе и `1` при ошибке. 
Программа сообщает пользователю понятную причину сбоя (без страшных стек-трейсов). 

Обрабатываются следующие ситуации:
* отсутствующий или некорректный аргумент;
* город не найден (пустой результат геокодинга);
* ответ со статусом 4хх;
* ответ со статусом 5хх;
* отсутствие сети;
* превышение таймаута;
* некорректный JSON в ответе.

##  Структура проекта
* `src/index.js` — разбор аргументов и запуск.
* `src/api/` — клиент внешнего API.
* `src/services/` — бизнес-логика.
* `src/storage/` — файлы и кэш.
* `src/format/` — форматирование и вывод.
* `docs/postman/` — экспортированная коллекция Postman с примерами ответов.
